This package adds editable data-cms selectors to the main index.html and expands cms-defaults.js with all detected website text/media fields.

After uploading to GitHub Pages:
1. Open https://rajagencies.info/admin.html
2. Login
3. Click Load Default Fields
4. Click Save Live Changes
5. Search for any text such as ₹80Cr+, 1997, Current business scale, branches, certificate, etc.

Existing Firebase data currently contains only old fields; Load Default Fields is required once after upload.
